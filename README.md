# Tuesday Lounge Bar

Production-ready bilingual website for Tuesday Lounge Bar in Aktau, Kazakhstan.

## Routes

- `/` — editorial home experience
- `/menu` — verified popular dishes and current-menu contact links
- `/booking` — validated WhatsApp reservation request flow

## Local development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`. Set `NEXT_PUBLIC_SITE_URL` to the final public origin before deployment so canonical URLs, the sitemap, and social metadata use the live domain.
